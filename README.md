# Overall Build Group Website

This repository contains the exported source for the Overall Build Group semi custom kitchen website.

## Contents

`index.html` contains the complete responsive website page, including styles, interactive FAQ behavior, search structured data, and externally hosted image references.

## Viewing the Website

Open `index.html` in a modern browser to view the page locally.

## Before Publishing

Update the placeholder business name, contact details, city, canonical address, and search structured data values before publishing the website.

## Vercel Deployment

This is a static site with its entry page at the repository root. Import the repository into Vercel and allow it to deploy the files as they are. No package installation, build command, output directory, or `vercel.json` file is needed for this version.

Before the first production deployment, replace the placeholder business name, phone number, service area, licence details, canonical address, and structured data values in `index.html`.
